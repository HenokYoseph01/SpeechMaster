# Bundled fonts

Downloaded from Google's font repository on 2026-10-12:

- [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito): variable upright font.
- [Noto Sans Ethiopic](https://github.com/google/fonts/tree/main/ofl/notosansethiopic): variable upright font used as the Amharic fallback.

Both fonts are distributed under the SIL Open Font License. The original
license files are included alongside the fonts. No runtime font download is used.
